# Спотмап · Ижевск

Flutter-приложение с картой культурных мест Ижевска. Гуляете по городу, находите
на карте парки, памятники, музеи, театры и родники — и отмечаете те, где уже
побывали.

## Что умеет

- показывает карту Ижевска на OpenStreetMap;
- отмечает на карте 300+ реальных мест из OpenStreetMap;
- фильтрует места по категориям: парки, памятники, музеи, родники, театры,
  достопримечательности, фонтаны;
- показывает текущее местоположение и точность GPS;
- отмечает посещение **только вручную** кнопкой в карточке места;
- сохраняет отмеченные места на устройстве (`shared_preferences`);
- считает прогресс «Открыто N из M»;
- считает **шаги за сегодня** по перемещению GPS (оценка, пока приложение
  открыто);
- показывает **отдельный список всех мест** с поиском и фильтрами по
  посещению, категории и сортировкой по расстоянию;
- адаптирован под телефоны: компактная шапка, безопасные отступы, компактные
  фильтры и нижние карточки;
- при отдалении **объединяет маркеры в кластеры** с количеством мест, чтобы
  карта не тормозила;
- показывает **пройденные зоны**: сетку квадратов 500 × 500 м. Квадрат, по
  которому вы прошли, открывается навсегда. При отдалении соседние квадраты
  объединяются, как маркеры в кластеры, — до 5 км;
- ведёт **достижения** за посещённые места, категории и пройденные зоны;
- показывает **«Что рядом»** — ближайшие места с сортировкой по расстоянию
  и фильтром по радиусу;
- кэширует **тайлы карты** на устройстве: просмотренные места открываются
  без интернета, а текущий вид можно скачать заранее;
- работает без интернета на сохранённом наборе мест, а при наличии сети
  обновляет данные через Overpass API не чаще раза в сутки (кнопка в меню
  обновляет вручную в любой момент).

## Пройденные зоны и шаги

Сетка привязана к прямоугольнику Ижевска. При попадании координат в квадрат
он открывается и сохраняется в `shared_preferences` — при следующем запуске
останется открытым. Базовый размер квадрата — 500 × 500 м, но на отдалении
для отрисовки соседние квадраты объединяются: 1 км, 1,5 км, 2 км, 3 км и
максимум 5 км. Так на карте остаётся меньше линий и вырезов, а зоны выглядят
крупнее — по тому же принципу, что и кластеры маркеров.

Ранее открытые квадраты из старой версии приложения переносятся в новое
хранилище автоматически, поэтому прогресс не пропадёт после обновления.

Шаги считаются по пройденному GPS-расстоянию: длина шага принята 0,72 м,
GPS-дрожание меньше 1,8 м игнорируется. Счётчик сбрасывается в полночь.
Это оценка, а не показания системного шагомера.

## Достижения

Достижения не хранятся отдельно: они пересчитываются по отмеченным местам,
категориям и пройденным зонам. Это первые отметки, четверть/половина/весь
город, отдельные цели по паркам, памятникам, музеям, родникам и театрам,
а также зоны и количество посещённых категорий. Новые достижения показываются
всплывающим сообщением, а полный список с прогрессом — на экране «Достижения»
(иконка кубка в шапке).

## Что рядом

Кнопка со стрелкой в шапке открывает ближайшие места. Они отсортированы по
расстоянию, можно выбрать радиус 500 м, 1 км, 3 км, 5 км или весь город.
Нажатие на место центрирует на нём карту и открывает карточку.

## Офлайн-карта

Тайлы OpenStreetMap сохраняются на устройстве через `flutter_map_cache` и
Hive, поэтому уже просмотренные районы открываются без интернета. В меню
«Ещё» → «Офлайн-карта» можно заранее скачать текущий вид: до 400 тайлов на
зумах 10–16 и очистить кэш. Ограничение сделано, чтобы не создавать лишнюю
нагрузку на серверы OpenStreetMap.

## Запуск

```bash
flutter pub get
flutter run
```

Перед запуском на Android/iOS разрешите приложению доступ к геопозиции.

### Платформы

- **Android** — разрешения на интернет и геопозицию уже прописаны.
- **iOS/macOS** — добавлено описание доступа к геопозиции.
- **Web** — геолокация браузера работает только по HTTPS (или на `localhost`).
- **Windows** — геолокация зависит от службы геопозиции Windows.
- **Linux** — геолокация плагином не поддерживается, отметки можно ставить
  вручную.

## Данные

Данные взяты из OpenStreetMap (лицензия ODbL, © OpenStreetMap contributors).
Снимок `izhevsk_spots.json` пересобран из актуальных данных OSM по
прямоугольнику Ижевска: 332 объекта с тегами `tourism`, `historic`, `leisure`,
`natural=spring` и `amenity`. Дополнительно вручную добавлены «Памятник
пельменю» и «Памятник собаке-космонавту Звёздочке», которых нет в OSM.
Точки с чужими координатами, дубли и животные контактного зоопарка удалены.
